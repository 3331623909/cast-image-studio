# Manga impact

![Reference](reference.webp)

- Oversized slanted display lettering with radiating speed lines, for one extreme beat.
- Heavy outline, flat fill, one bright accent colour at most.
- Use it for exactly one beat on the page. Impact lettering everywhere means impact nowhere.
- The acting face must stay visible around or between the letters.

Prompt fragment: Use oversized slanted manga impact lettering with radiating speed lines, heavy outline and one bright accent colour, for exactly one beat on the page, with the acting face still visible between the letters.
