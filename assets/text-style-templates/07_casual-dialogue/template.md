# Casual dialogue

![Reference](reference.webp)

- Small relaxed balloons set close to the speaker: everyday chat, gentle teasing, comfort, food.
- Neat rounded lettering, light outline, warm and quiet.
- This is the default when nothing in the panel needs emphasis.
- Still one balloon per speaker; never merge two speakers into one container.

Prompt fragment: Use small relaxed speech balloons with neat rounded lettering and a light outline, set close to each speaker, warm and quiet; one balloon per speaker and never two speakers in one container.
