# Caption box

![Reference](reference.webp)

- A clean rectangular narration box, parallel to the panel edge, usually at the top or bottom of a panel.
- Plain readable lettering. This is the story's own voice, so it carries no speaker tail.
- Captions never belong to a character's mouth and never point at anyone.
- Keep a caption box out of the faces and out of the acting gesture.

Prompt fragment: Use a clean rectangular narration caption box set parallel to the panel edge with plain readable lettering, carrying the story's own voice; a caption has no speaker tail, points at nobody, and never covers a face or the acting gesture.
